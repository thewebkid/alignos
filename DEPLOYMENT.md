# AlignOS Deployment (Vercel)

AlignOS is a static Vue 3 + Vite SSG site. Production runs on **Vercel**.

## Project setup

1. Create a Vercel project named `alignos-reader` (or similar).
2. Link the GitHub repo `thewebkid/alignos`.
3. Set **Root Directory** to `client`.
4. Framework preset: Vite (auto-detected). Build command `npm run build`, output `dist`.
5. Enable **Web Analytics** in the Vercel project settings.

`client/vercel.json` provides `cleanUrls` and rewrites that preserve the public LLM API:

| Public URL | Static file |
|---|---|
| `/api/health` | `/data/health.json` |
| `/api/codex-lattice` | `/data/codex-lattice.json` |
| `/api/codex-lattice-meta` | `/data/codex-lattice-meta.json` |
| `/api/codex/:id` | `/data/codex/:id.json` |

These JSON files are generated by `npm run build:lattice` during the client build.

## Custom domain

DNS for `cosmiccreation.net` stays in **Azure DNS**.

1. In Vercel: **Add** domain `alignos.cosmiccreation.net`.
2. In Azure DNS: set `alignos` **CNAME** to the target Vercel shows (typically `cname.vercel-dns.com`).
3. Leave the apex `@` A record alone (astrosurf redirect).

## Local development

```powershell
cd c:\src\alignos\client
npm install
npm run dev
```

Dev server includes the same `/api/*` → `/data/*.json` rewrites as production.

```powershell
npm run build
npm run preview
```

## Analytics

- **Vercel Web Analytics** via `@vercel/analytics`
- Custom events still go through `src/lib/tracker.js` (`track('eventName', props)`)
- Opt out: visit `/notrack` (sets `localStorage.notrack`)

## What was removed

The former Windows self-host stack is gone:

- Express server + MongoDB (unused) + Prometheus
- Umami reverse-proxy (`/stats`)
- PM2 / Caddy / `deploy.ps1` / `setup-staging.ps1`
